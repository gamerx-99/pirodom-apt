# คู่มือผู้เช่า

ใช้งานผ่าน LINE ทั้งหมด ไม่ต้องติดตั้งแอปเพิ่ม

## ผูกห้องครั้งแรก

1. เพิ่มเพื่อน LINE ของหอพัก
2. ขอรหัสยืนยันจากเจ้าของหรือแอดมิน (รหัสใช้ได้ครั้งเดียว ภายใน 7 วัน)
3. พิมพ์รหัสส่งเข้าแชทส่วนตัวกับ LINE ของหอ
4. บอทจะตอบกลับพร้อมลิงก์เข้าระบบผู้เช่า กดลิงก์แล้วอนุญาตให้เข้าถึงบัญชี LINE

ถ้ารหัสหมดอายุหรือถูกยกเลิกแล้ว ให้ขอรหัสใหม่จากแอดมิน

## เมนูในระบบผู้เช่า

- **หน้าหลัก** ยอดค้างชำระและวันครบกำหนด
- **บิล** รายละเอียดค่าเช่า ค่าน้ำ ค่าไฟ
- **มิเตอร์** ประวัติเลขมิเตอร์และหน่วยที่ใช้ของห้อง
- **เอกสาร** สัญญาและเอกสารของห้อง
- **แจ้งซ่อม** แจ้งปัญหาพร้อมรูป และติดตามสถานะ

## จ่ายค่าเช่า

1. เปิดบิลที่ต้องการจ่าย
2. สแกน QR PromptPay บนบิลด้วยแอปธนาคาร (QR มียอดเงินตรงตามบิลอยู่แล้ว)
3. โอน**เต็มยอดบิล** ระบบไม่รับยอดบางส่วน
4. กลับมาที่หน้าบิล แล้วส่งรูปสลิป
5. รอผลตรวจทาง LINE: อนุมัติแล้ว หรือถูกปฏิเสธพร้อมเหตุผล ถ้าถูกปฏิเสธ ให้ติดต่อแอดมิน

ห้ามส่งสลิปเดิมซ้ำ ระบบจะตรวจพบสลิปซ้ำ
