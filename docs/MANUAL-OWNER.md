# คู่มือเจ้าของ / แอดมิน

เข้าระบบที่ `https://pirodom-apt.vercel.app/admin` ด้วยบัญชี LINE ที่ได้สิทธิ์เจ้าของหรือแอดมิน

## เริ่มใช้ครั้งแรก (ทำครั้งเดียว)

1. **ตั้งค่าระบบ** (`ตั้งค่าระบบ`)
   - PromptPay: เบอร์มือถือ 10 หลักหรือเลข 13 หลัก และชื่อบัญชีที่จะแสดงใต้ QR
   - SlipOK: Branch ID และ API Key (ถ้าไม่ใส่ สลิปจะเข้าคิวให้ตรวจเอง)
   - LINE: Login Channel ID, Messaging API Channel secret และ access token
   - กดบันทึก มีผลทันที ไม่ต้อง deploy ใหม่ ช่องคีย์ลับเว้นว่างไว้ได้ ระบบจะใช้ค่าเดิม
   - เพิ่มแอดมินคนอื่นได้ด้วย LINE User ID ในหน้าเดียวกัน
2. **ห้องพัก** (`ห้องพัก`) เพิ่มทุกยูนิต พร้อมค่าเช่า เงินประกัน ค่าน้ำเหมาจ่าย ค่าไฟต่อหน่วย และวันครบกำหนดชำระ
   - ราคาของห้องที่มีสัญญาอยู่จะล็อกไว้ แก้ได้หลังปิดสัญญาเท่านั้น
   - ลบห้องได้เฉพาะห้องที่ไม่เคยมีสัญญา มิเตอร์ หรืองานซ่อมผูกอยู่

## รับผู้เช่าใหม่

1. `สัญญา` เลือกห้อง ระบบจะดึงราคาจากห้องมาให้ แก้เฉพาะสัญญานี้ได้ แล้วกด **สร้างสัญญา**
2. กด **ออกรหัสยืนยัน (7 วัน)** รหัสจะแสดงครั้งเดียว ส่งให้ผู้เช่า
3. ผู้เช่าพิมพ์รหัสส่งเข้าแชท LINE ของหอ บอทจะผูกบัญชีและส่งลิงก์เข้าระบบผู้เช่ากลับไป
4. ผู้เช่าย้ายออก: กด **ปิดสัญญา** ห้องจะกลับเป็นว่าง และรหัสที่ยังไม่ใช้จะถูกยกเลิก

## รอบบิลประจำเดือน

1. `จดมิเตอร์` บันทึกเลขมิเตอร์วันไหนก็ได้ แนบรูปได้ ระบบเตือนถ้าเลขลดลงหรือใช้ผิดปกติ
2. `บิลและใบแจ้งหนี้` เลือกสัญญาและแถวมิเตอร์ แล้วกด **สร้างบิลร่าง**
   - ใส่ค่าปรับหรือรายการอื่นในช่อง "รายการเพิ่ม" และใส่ส่วนลดในช่อง "ส่วนลด" ต้องระบุเหตุผลทุกครั้ง
   - ตรวจยอดให้ถูกก่อน แล้วค่อยออกบิล ผู้เช่าจะเห็นบิลใน LINE
3. ระบบรับชำระ**เฉพาะเต็มยอด**เท่านั้น ไม่รับจ่ายบางส่วนหรือเกิน

## ตรวจสลิป

- `ตรวจสลิป LINE` แสดงสลิปที่รอตรวจ ถ้าตั้งค่า SlipOK ไว้ ระบบจะตรวจยอดและสลิปซ้ำให้ก่อน
- กด **อนุมัติและปิดบิล** หรือ **ปฏิเสธ** (ต้องใส่เหตุผล) ผู้เช่าจะได้รับแจ้งผลทาง LINE
- มุมบนของหน้าแอดมินจะแจ้งเตือนเมื่อมีสลิปหรืองานซ่อมใหม่เข้ามา

## งานซ่อม เอกสาร ข้อความ

- `งานซ่อมบำรุง` รับเรื่อง อัปเดตสถานะ และปิดงาน
- `เอกสาร` อัปโหลดสัญญาหรือเอกสารของแต่ละสัญญา ผู้เช่าเห็นเฉพาะเอกสารของตัวเอง
- `ส่งข้อความ` ส่งข้อความ LINE ถึงทุกห้อง เฉพาะห้องที่ค้างชำระ หรือเลือกเองทีละห้อง ถ้าส่งไม่สำเร็จ กด **ส่งซ้ำ** จากประวัติได้

## ข้อควรระวัง

- คนที่รู้ access token หรือคีย์ SlipOK ใช้ระบบในนามหอได้ อย่าส่งคีย์ทางแชท
- ก่อนเชิญผู้เช่าจริง ให้ลบห้องและสัญญาที่สร้างไว้ทดสอบออกก่อน
- ถ้าระบบมีปัญหา ดูขั้นตอนกู้คืนใน [OPERATIONS.md](OPERATIONS.md)
